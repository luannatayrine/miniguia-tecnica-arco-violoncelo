# Prompts utilizados

Esta pasta documenta os prompts utilizados como apoio ao processo de pesquisa, análise, comparação e síntese das fontes do projeto.

Os prompts foram utilizados principalmente para:

- identificar relações entre as fontes;
- comparar diferentes abordagens;
- verificar se determinadas afirmações estavam realmente sustentadas pelas referências;
- distinguir evidências de inferências;
- organizar recomendações de forma rastreável;
- construir uma síntese integrada das três fontes.

A utilização dos prompts teve como princípio a verificação das informações nas fontes originais, evitando completar lacunas com conhecimento externo ou apresentar inferências como afirmações dos autores.

## Prompts reutilizáveis

Além de documentar o processo de desenvolvimento deste projeto, alguns prompts podem ser reutilizados em futuras pesquisas.

### Verificação de evidência

> Para cada afirmação apresentada, indique qual fonte a sustenta. Caso a informação não esteja claramente presente na fonte, classifique-a como inferência ou como não suficientemente sustentada.

### Comparação entre fontes

> Compare as fontes selecionadas sobre [TEMA]. Identifique convergências e divergências. Para cada afirmação, indique qual fonte a sustenta. Não considere duas fontes concordantes sem verificar evidências em ambas.

### Revisão crítica

> Revise a resposta anterior procurando afirmações que possam ter sido inferidas, generalizadas ou atribuídas incorretamente às fontes. Identifique cada problema e explique como corrigi-lo sem utilizar conhecimento externo.

### Síntese

> Construa uma síntese sobre [TEMA] utilizando exclusivamente as fontes fornecidas. Diferencie claramente informações diretamente sustentadas pelas fontes de sínteses e interpretações.

### Extração de recomendações

> Extraia das fontes as práticas ou recomendações relacionadas a [TEMA]. Para cada recomendação, indique a fonte e classifique-a como explicitamente recomendada, síntese/interpretação ou não suficientemente sustentada.
