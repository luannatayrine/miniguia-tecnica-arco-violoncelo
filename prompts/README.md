# Prompts utilizados

Esta pasta documenta os prompts utilizados como apoio ao processo de pesquisa, análise, comparação e síntese das fontes do projeto.

Os prompts foram utilizados principalmente para:

- identificar relações entre as fontes;
- comparar diferentes abordagens;
- verificar se determinadas afirmações estavam realmente sustentadas pelas referências;
- distinguir evidências de inferências;
- organizar recomendações de forma rastreável;
- construir uma síntese integrada das três fontes.

A utilização dos prompts teve como princípio a verificação das informações nas fontes originais, evitando completar lacunas com conhecimento externo ou apresentar inferências como afirmações dos autores.
